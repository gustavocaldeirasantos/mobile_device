📱 Mobile Behavior Insights: O que os nossos telemóveis dizem sobre nós?
Bem-vindo(a) ao meu projeto de análise exploratória de dados! Aqui, mergulhei num conjunto de dados sobre o uso de dispositivos móveis para entender padrões de comportamento, diferenças entre sistemas operativos e perfis de consumo.

🎯 O Objetivo
O objetivo principal deste projeto foi transformar dados brutos em conhecimento visual. Procurei responder a perguntas como:

Será que utilizadores de Android e iOS usam o telemóvel de forma diferente?

Como o tempo de ecrã influencia o gasto de bateria?

Existe uma correlação real entre a idade do utilizador e o número de aplicações instaladas?

🛠️ Ferramentas Utilizadas
Para este desafio, utilizei o ecossistema Python, com foco em:

Pandas & Numpy: Para a limpeza e manipulação dos dados.

Matplotlib & Seaborn: Para a criação de visualizações elegantes e intuitivas (com temas personalizados para portfólio).

📊 O que foi analisado?
O projeto está dividido em etapas lógicas de descoberta:

Demografia vs. Tecnologia: Uma visão geral de como os géneros e sistemas operativos (Android vs. iOS) se distribuem na amostra.

Métricas de Uso: Análise do tempo de uso diário, tempo de ecrã ligado e consumo de dados.

Saúde do Dispositivo: Investigação sobre o consumo de bateria e a quantidade de apps que cada perfil costuma manter.

Segmentação de Comportamento: Agrupamento dos utilizadores em classes (User Behavior Class) para entender perfis "Hard User" vs. "Light User".

🚀 Como visualizar
O projeto está documentado num Jupyter Notebook (mobile_device.ipynb). Podes ver:

O código limpo e comentado.

Gráficos de barras, histogramas e tabelas de frequência.

A exportação final de uma imagem de análise (analise_comportamento.png) que resume os principais achados.

💡 Insights extraídos (Exemplos)
A base analisada conta com uma forte presença de utilizadores Android (79%) em comparação ao iOS (21%).

A distribuição de género é equilibrada, com 52% de homens e 48% de mulheres.
